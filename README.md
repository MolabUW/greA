# greA

This is the code for the project [preprint link here]

There are two primary analyses:

1.  The greA gene phylogeny, explained in `methods.md`

2.  The CRISPR analysis in the publicly available host genomes, explained in `methods.md`. For this analysis, the HTCondor files are in `Scripts` (container definition file, sub and sh scripts) and the R script used for data vizualisation is `Host-crispr.Rmd`. The input data for the Rscript are in `Data`.
